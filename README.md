# Diagram Hackathon

Static HTML flow for the LINE carry-along shopping project, including screen wireframes and notification handoffs.

## Deploy on Vercel

Import this repository with these settings:

- Framework Preset: Other
- Root Directory: repository root
- Build Command: leave empty
- Output Directory: `.`

The entry page is `index.html`. No package installation or build step is required.

All prices, fees, and payment states shown are examples for discussion. This site does not connect to LINE or process payments.
